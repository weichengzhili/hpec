# 交叉编译与构建

> 模块目录：`workspace/foundation/rust-cross-build/` · 接口文件：`build.rs`

## 0. 问题定位

- **解决什么问题**：目标三元组、链接脚本、build.rs 如何正确。
- **边界标准**：
  1. 目标三元组正确，链接脚本与内存布局匹配，构建可复现。
- **系统位置**：环 1、环 10。

## 1. 模块定位与目标
建立 Rust 嵌入式交叉编译与构建体系：目标三元组（target triple）、Cargo 配置、build.rs 生成、链接脚本与固件打包，支持 RK3588(aarch64)、Cortex-M、RISC-V 等目标。

**服务场景**：所有 Rust 嵌入式模块的构建与发布。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 目标 | aarch64-unknown-linux-gnu、thumbv7em-none-eabi、riscv32 |
| 工具链 | rustup target 添加、链接器 |
| 约束 | 无 std 目标需自定义运行时/链接脚本 |

## 3. 架构设计

### 3.1 构建链路
```
源码 → cargo build → 依赖编译 → 链接(目标链接器) → ELF → objcopy → 固件(bin/hex)
```

### 3.2 关键配置
| 配置 | 位置 | 说明 |
|------|------|------|
| 目标三元组 | .cargo/config.toml | 指定 target |
| 链接脚本 | build.rs 或 config | 段布局 |
| 依赖特性 | Cargo.toml | 按目标启用特性 |
| 工具链 | rust-toolchain.toml | 版本固化 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `build.rs` | 目标判定、链接脚本、代码生成 |
| `.cargo/config.toml` | 默认 target 与链接器 |
| `rust-toolchain.toml` | 工具链版本固化 |

**build.rs 关键逻辑**：根据 `TARGET` 环境变量判断裸机/OS 目标，设置链接参数。

## 5. 关键流程与时序
cargo 解析依赖 → 编译 crate → build.rs 执行 → 链接 → 生成 ELF → 后处理为烧录格式。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 版本 | rust-toolchain.toml 固化 | 跟随最新 | 可复现构建 |
| 特性 | 按目标条件启用 | 全开 | 控制体积/功能 |
| 打包 | objcopy 生成 bin/hex | 仅 ELF | 烧录兼容 |

## 7. 性能指标（KPI）
- 构建可复现（同工具链同产物）。
- 产物体积可量化。

## 8. 可靠性设计
- 锁定依赖（Cargo.lock）+ 工具链版本，防漂移。

## 9. 安全设计
- 供应链安全：依赖审计、cargo audit。

## 10. 测试与验证策略
- 主机单测 + 目标集成测试 + 仿真。

## 11. 集成与部署
- 容器化构建环境，跨机器一致。

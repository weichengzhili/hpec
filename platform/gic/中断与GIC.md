# 中断与 GIC

> 模块目录：`workspace/platform/gic/` · 接口文件：`include/gic.h`

## 1. 模块定位与目标
建立 RK3588 中断体系方案：GIC-600 中断控制器、SPI/PPI/SGI 中断类型、中断分发与优先级，支撑外设中断与跨核通信，满足实时性要求。

**服务场景**：实时控制、外设中断处理、多核通信（域控/机器人）。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 控制器 | GIC-600（GICv3 架构） |
| 类型 | SGI（核间）/ PPI（私有）/ SPI（共享外设）/ LPI |
| 约束 | 中断延迟与抖动受限（实时场景） |

## 3. 架构设计

### 3.1 GIC 结构
| 组件 | 职责 |
|------|------|
| Distributor | 中断分发、优先级、使能 |
| Redistributor | 每核中断配置（PPI/SGI） |
| CPU Interface | 中断确认与优先级屏蔽 |

### 3.2 中断类型
| 类型 | 编号 | 用途 |
|------|------|------|
| SGI | 0-15 | 软件触发核间中断（IPI） |
| PPI | 16-31 | 每核私有（定时器） |
| SPI | 32+ | 共享外设中断 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `gic_irq_type_t` | 中断类型 |
| `gic_priority_t` | 优先级枚举 |
| `gic_init/enable_irq/disable_irq()` | 初始化和控制 |
| `gic_set_priority/set_target_cpu()` | 优先级与亲和 |
| `gic_send_sgi()` | 核间中断 |
| `gic_register_handler()/end_of_interrupt()` | 处理注册与 EOI |

## 5. 关键流程与时序
外设触发 → Distributor 分发 → 目标核 CPU Interface 响应 → 进入中断处理 → 上半部 + 下半部（见 kernel/irq）。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 处理 | 线程化中断 | 纯上半部 | 降低延迟影响 |
| 亲和 | 绑定核 | 任意 | 缓存局部性/实时隔离 |
| 优先级 | 关键中断高优先级 | 平均 | 实时保证 |

## 7. 性能指标（KPI）
- 中断延迟（事件到处理）与抖动量化。
- 中断处理时长有界。

## 8. 可靠性设计
- 中断丢失检测、风暴防护。
- 共享中断正确处理（遍历处理函数）。

## 9. 安全设计
- 关键安全中断优先级最高、不可屏蔽干扰。

## 10. 测试与验证策略
- 中断延迟/抖动实测（逻辑分析仪）。
- 多核中断压力测试。

# 时钟与电源管理

> 模块目录：`workspace/platform/clock-power/` · 接口文件：`include/cru.h`

## 1. 模块定位与目标
建立 RK3588 时钟（CRU）与电源（PMU/功耗域）管理方案：时钟树、PLL 配置、功耗域开关、DVFS 调频调压，实现性能与功耗平衡，支撑域控/网关的功耗与散热要求。

**服务场景**：低功耗 IoT 边缘、域控热设计、网关功耗预算。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 时钟 | CRU 统一时钟树，PLL/分频/门控 |
| 电源 | 多功耗域（CPU/GPU/NPU/VPU 等独立） |
| DVFS | 按负载调频调压 |
| 约束 | 切换功耗域需时序正确，防止毛刺 |

## 3. 架构设计

### 3.1 时钟体系
```
外部晶振 → PLL → 分频器 → 各外设时钟（门控）
```
- 关键时钟：CPU、GPU、NPU、内存、总线、外设。
- 门控时钟：空闲外设关断省电。

### 3.2 电源体系
| 层 | 说明 |
|----|------|
| PMIC | 外部电源管理芯片 |
| PMU | 芯片内电源管理单元 |
| 功耗域 | CPU/GPU/NPU/VPU/多媒体独立上下电 |
| DVFS | OPP 表：频率-电压点 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `clk_id_t` | 时钟 ID |
| `power_domain_t` | 功耗域 |
| `cru_clk_enable/disable/set_rate/get_rate()` | 时钟操作 |
| `pmu_pd_power_on/off/is_on()` | 功耗域操作 |
| `opp_point_t` | DVFS 频率-电压点 |
| `dvfs_set_opp/get_opp_table()` | DVFS 操作 |

## 5. 关键流程与时序
驱动 probe → 获取使能时钟 → 使能功耗域 → 配置频率 → 使用外设 → 释放时反序关闭。pm_runtime 自动在空闲时下电。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 电源 | 功耗域独立 | 全局 | 精细化省电 |
| DVFS | OPP 表 + 调度器联动 | 固定频率 | 性能功耗平衡 |
| 管理 | Linux clk/PM 框架 | 自研 | 复用成熟机制 |

## 7. 性能指标（KPI）
- 各负载档功耗量化。
- 空闲功耗目标（IoT 边缘）。
- DVFS 切换延迟符合场景。

## 8. 可靠性设计
- 上电时序校验，防时序错误。
- 温度监控联动降频/降功耗。

## 9. 安全设计
- 关键功耗域切换受控，防误关断核心。

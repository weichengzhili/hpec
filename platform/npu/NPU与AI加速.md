# NPU 与 AI 加速

> 模块目录：`workspace/platform/npu/` · 接口文件：`include/npu.h`

## 1. 模块定位与目标
建立 RK3588 NPU（三核，6 TOPS）的 AI 加速方案：RKNN 工具链、模型转换、推理部署、算子支持与性能优化，为边缘 AI 提供高能效推理算力。

**服务场景**：AI 边缘部署、视觉感知、舱内检测、机器人视觉、网关智能分析。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 算力 | 6 TOPS（INT8） |
| 工具链 | RKNN-Toolkit 转换模型 |
| 约束 | 算子支持范围、精度（INT8/FP16）权衡 |

## 3. 架构设计

### 3.1 部署流程
```
训练框架模型(PyTorch/ONNX) → RKNN-Toolkit 转换/量化 → .rknn 模型 → RKNN Runtime 推理
```

### 3.2 NPU 架构
| 组件 | 说明 |
|------|------|
| 三核 NPU | 并行计算单元 |
| 片上 SRAM | 权重/特征缓存 |
| 与内存/DMA 协同 | 数据搬运（见 dma-engine） |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `npu_tensor_type_t/layout_t` | 张量类型/布局 |
| `npu_tensor_t` | 张量描述（零拷贝 DMA 缓冲） |
| `npu_init/get_input_attr/get_output_attr()` | 模型加载与属性 |
| `npu_set_input/set_output()` | 输入输出设置 |
| `npu_inference()/destroy()` | 推理与释放 |
| `npu_model_verify()` | 模型完整性校验 |

## 5. 关键流程与时序
加载 .rknn → 分配输入/输出张量 → 预处理（归一化/缩放）→ 推理 → 后处理 → 输出。输入输出张量走 DMA 零拷贝。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 精度 | INT8 为主 | FP32 | 能效比最高 |
| 转换 | RKNN 工具链 | 通用 | 官方支持最佳 |
| 内存 | 零拷贝 DMA | 拷贝 | 降低搬运开销 |

## 7. 性能指标（KPI）
- 推理延迟（单帧）、吞吐（FPS）。
- 模型精度损失（量化前后）。
- NPU 利用率与功耗。

## 8. 可靠性设计
- 推理超时看护、异常恢复。
- 模型完整性校验。

## 9. 安全设计
- 模型加密/签名防篡改。
- 推理数据隔离。

## 10. 测试与验证策略
- 模型精度回归（量化前后比对）。
- 推理压力与稳定性测试。

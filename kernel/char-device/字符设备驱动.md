# 字符设备驱动

> 模块目录：`workspace/kernel/char-device/` · 接口文件：`include/cdev.h`

## 1. 模块定位与目标
建立字符设备驱动开发方案：字符设备注册、file_operations 实现、ioctl/mmap/读写接口，为自定义外设提供用户态访问入口。

**服务场景**：RK3588 定制外设、FPGA 协处理器、传感器/执行器访问。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 模型 | 字符设备（cdev） |
| 接口 | open/read/write/ioctl/mmap/poll |
| 约束 | 与设备树/平台驱动结合（见 platform-driver） |

## 3. 架构设计
```
用户态应用 → 系统调用 → VFS → 字符设备驱动 → 硬件
```

### 3.1 核心接口
| 接口 | 说明 |
|------|------|
| open/release | 打开/关闭 |
| read/write | 数据读写 |
| ioctl | 控制命令 |
| mmap | 内存映射（DMA 缓冲） |
| poll | 事件等待 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `cdev_ops_t` | 字符设备操作 |
| `cdev_register/unregister()` | 注册/注销 |
| `copy_to_user/copy_from_user()` | 用户态数据拷贝 |

## 5. 关键流程与时序
用户态 open → 驱动 open → 分配资源 → read/write/ioctl → 硬件交互 → release 释放。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 控制 | ioctl | 仅读写 | 命令灵活 |
| 大数据 | mmap | read/write | 零拷贝 |
| 事件 | poll/等待队列 | 轮询 | 异步通知 |

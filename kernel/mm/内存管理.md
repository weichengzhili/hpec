# 内存管理

> 模块目录：`workspace/kernel/mm/` · 接口文件：`include/mm.h`

## 1. 模块定位与目标
建立内核内存管理方案：虚拟内存/页管理、slab 分配器、内存映射、内存回收，支撑系统稳定运行与设备 DMA 缓冲分配。

**服务场景**：RK3588 系统内存规划、DMA 缓冲、AI/流媒体大内存、网关长连接内存。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 机制 | 页管理（buddy）、slab/slub |
| 约束 | 内核内存不可换出、需连续内存（DMA） |
| 约束 | 内存压力下回收与 OOM 处理 |

## 3. 架构设计

### 3.1 内存层次
| 层 | 说明 |
|----|------|
| 页分配（buddy） | 物理页分配 |
| slab/slub | 小对象缓存 |
| vmalloc | 虚拟连续非物理连续 |
| kmalloc | 物理连续小块 |

### 3.2 关键机制
- 内存映射（mmap）供用户态/DMA。
- 内存回收（kswapd）与 OOM killer。
- 内存水位线（watermark）。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `mm_alloc_pages/free_pages()` | 页分配 |
| `mm_kmalloc/kzalloc/kfree()` | slab 小对象 |
| `mm_vmalloc/vfree()` | 虚拟连续 |
| `mm_mmap/munmap()` | 内存映射 |
| `mm_total_pages/free_pages()` | 统计 |
| `mm_watermark_check()/reclaim()/oom_notify()` | 水位/回收/OOM |

## 5. 关键流程与时序
分配请求 → 按大小走 slab 或页分配 → 内存不足触发回收 → 仍不足 OOM。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 小对象 | slab | 页分配 | 高效复用 |
| 大块 | 页分配 | slab | 连续物理 |
| DMA | 预留/CMA | 普通 | 保证连续 |

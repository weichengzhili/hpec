# 平台驱动与设备树

> 模块目录：`workspace/kernel/platform-driver/` · 接口文件：`include/platform.h`

## 0. 问题定位

- **解决什么问题**：设备树 compatible 如何匹配到驱动并获取资源。
- **边界标准**：
  1. compatible 匹配唯一，资源获取完整。
- **系统位置**：环 3。

## 1. 模块定位与目标
建立平台驱动（platform driver）与设备树绑定方案：通过 compatible 匹配、获取时钟/中断/内存/引脚资源，实现板级硬件驱动标准化。

**服务场景**：RK3588 板级外设驱动（与 platform/devicetree-bsp 对应）。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 模型 | platform_bus |
| 匹配 | compatible 字符串 |
| 资源 | 时钟/中断/内存/引脚（见 device-model） |

## 3. 架构设计
```
设备树节点(compatible) → platform 总线 → platform_driver → probe 获取资源
```

### 3.1 资源获取
| 资源 | 接口 |
|------|------|
| 内存 | devm_get_mmio |
| 中断 | devm_get_irq |
| 时钟 | devm_get_clock |
| 引脚 | devm_get_pinctrl |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `platform_driver_t` | 平台驱动结构 |
| `platform_driver_register/unregister()` | 注册/注销 |
| `resource_type_t` | 资源类型 |
| `devm_get_irq/mmio/clock/pinctrl()` | 资源获取（devm 自动管理） |
| `of_device_is_available()/of_get_property()/of_get_interrupt()` | 设备树解析 |

## 5. 关键流程与时序
内核解析 DTB → 创建设备 → platform 总线匹配驱动 → probe → 获取资源 → 初始化硬件。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 绑定 | compatible | 硬编码 | 标准、可复用 |
| 资源 | devm_* 自动管理 | 手动 | 简化释放 |
| 配置 | 设备树 | 代码 | 板级可配 |

## 7. 性能指标（KPI）

## 8. 可靠性设计

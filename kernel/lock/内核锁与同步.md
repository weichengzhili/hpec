# 内核锁与同步

> 模块目录：`workspace/kernel/lock/` · 接口文件：`include/lock.h`

## 1. 模块定位与目标
建立内核并发同步方案：自旋锁、互斥量、读写锁、RCU、原子操作、完成量，正确处理多核与中断上下文共享数据，防竞态、防死锁、防优先级反转。

**服务场景**：内核驱动并发、多核共享数据、实时任务同步。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 上下文 | 进程上下文/中断上下文区分 |
| 约束 | 中断上下文禁用会 sleep 的锁 |
| 约束 | 持锁时长最小化 |

## 3. 架构设计

### 3.1 锁类型
| 锁 | 上下文 | 阻塞 | 场景 |
|----|--------|------|------|
| 自旋锁 (spinlock) | 中断/进程 | 忙等 | 短临界区 |
| 互斥量 (mutex) | 进程 | 睡眠 | 可阻塞 |
| 读写锁 (rwlock) | 进程/中断 | 按需 | 读多写少 |
| RCU | 进程 | 无 | 读多写少、免锁读 |
| 原子操作 | 通用 | 无 | 单变量 |
| 完成量 (completion) | 进程 | 睡眠 | 同步等待 |

### 3.2 实时约束
- PREEMPT_RT 下自旋锁变为可睡眠的 rt_mutex（见 realtime）。
- 优先级继承防反转。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `spin_lock/unlock/irqsave/irqrestore()` | 自旋锁 |
| `mutex_init/lock/trylock/unlock()` | 互斥量 |
| `read_lock/write_lock 等` | 读写锁 |
| `rcu_read_lock/unlock/synchronize_rcu 等` | RCU |
| `atomic_add/cmpxchg/read()` | 原子操作 |
| `completion_*` | 完成量 |

## 5. 关键流程与时序
进入临界区加锁 → 修改共享数据 → 解锁。中断上下文用 spin_lock_irqsave 防同核中断死锁。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 短临界区 | 自旋锁 | 互斥 | 低延迟 |
| 可阻塞 | 互斥量 | 自旋 | 允许睡眠 |
| 读多写少 | RCU | 读写锁 | 免锁读、高性能 |

## 7. 性能指标（KPI）
- 持锁时间可审计。
- 无死锁、无数据竞争。

## 8. 可靠性设计
- 锁顺序约定防死锁。
- 优先级反转防护（实时）。

## 9. 安全设计
- 共享数据访问权限隔离。

## 10. 测试与验证策略

- 死锁/竞态检测（lockdep）。

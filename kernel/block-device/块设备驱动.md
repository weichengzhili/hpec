# 块设备驱动

> 模块目录：`workspace/kernel/block-device/` · 接口文件：`include/block.h`

## 1. 模块定位与目标
建立块设备驱动方案：块层（block layer）、请求队列、IO 调度，支撑 eMMC/SD/NVMe/SATA 等存储设备访问。

**服务场景**：RK3588 系统存储（eMMC）、数据盘（NVMe/SATA）、SD 卡。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 层次 | 块层 + 设备驱动 |
| 约束 | 请求队列、IO 合并/调度 |
| 约束 | 与存储控制器驱动结合（见 platform/pcie-usb-storage） |

## 3. 架构设计
```
文件系统 → 块层(request_queue) → 块设备驱动 → 存储控制器 → 介质
```

### 3.1 块层职责
- 请求队列管理。
- IO 合并、排序、调度。
- 缓冲与缓存。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `bio_op_t` | IO 操作类型 |
| `bio_request_t` | IO 请求 |
| `request_queue_t` / `blk_mq_init_queue()` | 请求队列 |
| `gendisk_t` / `block_device_register()` | 块设备注册 |
| `block_queue_request_handler()/complete_request()` | 请求处理 |

## 5. 关键流程与时序
文件系统提交 IO → 块层合并/调度 → 驱动下发 → 存储控制器执行 → 完成回调 → 返回结果。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 队列 | blk_mq 多队列 | 单队列 | 高并发、低延迟 |
| 调度 | 按介质选调度器 | 固定 | 性能 |
| 缓存 | 页缓存 | 无 | 加速读写 |

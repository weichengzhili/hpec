# 内核架构总览

> 模块目录：`workspace/kernel/kernel-arch/` · 接口文件：`include/kernel.h`

## 1. 模块定位与目标
建立 Linux 内核整体架构认识：进程管理、内存管理、文件系统、网络、设备驱动等子系统及相互关系，为各内核模块深入设计提供全局视图。

**服务场景**：所有基于 Linux 的嵌入式系统的内核定制与开发。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 架构 | 宏内核（monolithic），模块化 |
| 版本 | 5.10（RK3588 常用 LTS）/ 6.x |
| 约束 | 内核态与用户态隔离、并发复杂 |

## 3. 架构设计

### 3.1 核心子系统
| 子系统 | 职责 |
|--------|------|
| 进程调度 | 任务调度（见 scheduler） |
| 内存管理 | 虚拟内存、页、slab（见 mm） |
| 虚拟文件系统 | 统一文件抽象 |
| 网络栈 | 协议栈与设备（见 net-device） |
| 设备驱动 | 硬件抽象（见 device-model/char-device） |
| 中断 | 中断处理（见 irq） |

### 3.2 内核态/用户态
- 用户态经系统调用进入内核态。
- 内核态运行于高特权级，访问硬件。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `kernel_module_register/unregister()` | 模块注册 |
| `KERNEL_EXPORT_SYMBOL` | 导出符号 |
| `kernel_version()/api_version()` | 版本信息 |
| `kernel_syscall_register()` | 系统调用约定 |

## 5. 关键流程与时序
系统调用 → 陷入内核 → 子系统处理 → 返回用户态。中断打断当前执行进入中断处理（见 irq）。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 内核类型 | 宏内核 + 模块 | 微内核 | 性能与灵活性 |
| 配置 | 裁剪定制 | 全量 | 嵌入式资源 |
| 实时 | PREEMPT_RT 可选 | 非实时 | 见 realtime |

## 7. 性能指标（KPI）
- 系统调用延迟、上下文切换开销。
- 内存占用、启动时间。

## 8. 可靠性设计
- 内核 panic 与看门狗。
- 模块隔离与错误处理。

## 9. 安全设计
- 用户态/内核态隔离、LSM（见 security）。

## 10. 测试与验证策略
- 内核 selftests、LTP。
- 稳定性压力测试。

## 11. 集成与部署
- 内核配置（defconfig）版本化。

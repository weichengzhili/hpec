# 中断安全与临界区

> 模块目录：`workspace/concurrency/interrupt-critical/` · 接口文件：`include/interrupt_critical.h`

## 0. 问题定位

- **解决什么问题**：中断与主循环共享数据如何无锁/原子地安全交互。
- **边界标准**：
  1. 关中断临界区时间有上界（如 < N μs，N 按实时预算定）（度量项）。
  2. SPSC 队列生产/消费边界明确，无数据竞争（硬约束）。
  3. 中断上下文禁止任何可能阻塞的调用（硬约束）。
- **系统位置**：环 4；`kernel/irq` → 本模块 → `fsm`、`lock`；横切环 6。

## 1. 模块定位与目标
规范中断上下文中的共享数据访问与临界区管理，保证原子性、可重入性、规避优先级反转。是实时控制、驱动、RTOS 应用的核心正确性要求。

**边界**：语言层并发原语；内核锁见 `kernel/lock`，中断下半部见 `kernel/irq`。

**服务场景**：汽车域控（实时中断）、工业机器人（编码器/伺服中断）、网关（网络/串口中断）、RK3588 驱动。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 实时性 | 中断延迟与关中断时长严格受限 |
| 并发 | 中断上下文、任务上下文、多核并发 |
| 可重入 | 中断处理不可阻塞、不可调用不可重入 API |
| 约束 | 关中断只用于极短临界区 |

## 3. 架构设计

### 3.1 执行上下文分类
| 上下文 | 阻塞性 | 优先级 | 限制 |
|--------|--------|--------|------|
| 中断（上半部） | 不可阻塞 | 最高 | 只做必须工作，禁止 sleep |
| 软中断/下半部 | 不可阻塞 | 高 | 有限延迟 |
| 内核线程/任务 | 可阻塞 | 中 | 可睡眠 |
| 用户态 | 可阻塞 | 低 | 需系统调用 |

### 3.2 临界区机制选型
| 机制 | 作用域 | 阻塞 | 场景 |
|------|--------|------|------|
| 关中断 (local_irq_disable) | 单核 | 否 | 极短临界区 |
| 自旋锁 | 多核 | 否（忙等） | 共享内存保护 |
| 自旋锁+关中断 | 多核+中断 | 否 | 与中断共享 |
| 互斥锁/信号量 | 任务间 | 是 | 可阻塞临界区 |
| 原子操作 | 单变量 | 否 | 计数器/标志 |
| 无锁队列 (SPSC) | 生产者-消费者 | 否 | 中断→任务传递 |

### 3.3 中断→任务数据传递
SPSC 无锁环形队列：ISR 只写（`spsc_push`），任务只读（`spsc_pop`），天然无竞态。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `critical_enter()/critical_exit()` | 临界区进入/退出（映射为关中断或锁） |
| `atomic_add_i32/fetch_i32/cmpxchg_i32/add_u32` | 原子操作 |
| `spsc_queue_init()` | 初始化无锁队列 |
| `spsc_push()` | ISR 侧入队 |
| `spsc_pop()` | 任务侧出队 |
| `spsc_count/empty/full()` | 状态查询 |

## 5. 关键流程与时序
```
进入 ISR → 读中断源 → 清中断标志 → 必要处理 → 数据推入 SPSC 队列
        → 退出 ISR → 唤醒任务 → 任务 pop 处理
```
约束：ISR 内禁用 printf、malloc、加互斥锁、长循环。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 中断工作划分 | 上半部极短 + 下半部 | 全在 ISR | 降低中断延迟 |
| ISR→任务 | SPSC 无锁队列 | 加锁队列 | 无阻塞、无锁、确定性 |
| 多核共享 | 自旋锁+关本地中断 | 仅自旋锁 | 防止同核中断死锁 |
| 优先级反转 | 优先级继承/天花板 | 无 | 避免高优先级任务被低优先级锁阻塞 |

## 7. 性能指标（KPI）
- 中断响应延迟（事件到 ISR 入口）量化并设阈值。
- 关中断/持锁最长时间可测量、可审计，设上限（如 < 10 µs）。
- ISR 执行时间 < 设计上限。

## 8. 可靠性设计
- 共享变量用 `volatile sig_atomic_t` 或原子类型。
- 中断标志丢失检测：ISR 内计数与任务消费计数比对。
- 中断风暴防护：单位时间中断次数超限则告警/降级。

## 9. 安全设计
- 中断向量与处理函数地址保护（MPU/TrustZone）。
- 关键安全中断最高优先级且不可屏蔽干扰。
- 防死锁：禁止持自旋锁时调用会 sleep 的函数。

## 10. 测试与验证策略
- 并发压力测试：多核 + 高频中断下共享数据一致性。
- 竞态检测工具（helgrind/ThreadSanitizer）。
- 中断延迟与抖动实测（示波器/逻辑分析仪）。

## 11. 集成与部署

- 关中断时长纳入 CI 静态审计。

# 软硬核 SoC / PS-PL

> 模块目录：`workspace/fpga/ps-pl-soc/` · 接口文件：`rtl/ps_pl_if.sv`

## 1. 模块定位与目标
建立 FPGA 上软核/硬核 SoC 方案：软核（MicroBlaze/Nios V）或硬核（Zynq PS），实现处理器与可编程逻辑（PL）协同，处理器跑软件、逻辑做实时/加速。

**服务场景**：机器人实时控制（软核+逻辑）、网关协议处理、PS-PL 协同系统。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 软核 | MicroBlaze / Nios V / RISC-V 软核 |
| 硬核 | Zynq/MPSoC 的 PS（ARM 核） |
| 协同 | PS/软核与 PL 通过 AXI 互联 |
| 约束 | 软核性能有限，复杂逻辑放 PL |

## 3. 架构设计

### 3.1 软核 vs 硬核
| 类型 | 特点 | 适用 |
|------|------|------|
| 软核 | 灵活、资源换 CPU | 定制控制 |
| 硬核 | 高性能、固定 | 复杂系统 |

### 3.2 PS-PL 协同
```
PS(CPU) ←AXI→ PL(逻辑/加速器)
```
- 处理器跑控制/协议，PL 做实时接口、算法加速。
- 通过 AXI-Stream/DMA 高效数据交换。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `ps_pl_top` | PS-PL 协同顶层 |
| `cpu_axi` | 处理器 AXI 主端口 |
| `irq_0/irq_1` | PL→处理器中断 |
| `dma_axi/dma_irq` | DMA 通道 |
| `soft_cpu_wrapper` | 软核例化封装 |

## 5. 关键流程与时序
处理器初始化 → 配置 PL → 数据经 AXI/DMA 交换 → 中断通知 → 协同处理。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 软核 vs 硬核 | 按性能需求 | 单一 | 成本/性能 |
| 协同 | AXI + DMA | 寄存器 | 高效数据交换 |
| 分工 | 处理器控制 + PL 实时 | 全软件 | 各取所长 |

# 硬件调试

> 模块目录：`workspace/fpga/debug/` · 接口文件：`rtl/ila_probe.sv`

## 1. 模块定位与目标
建立 FPGA 上板调试体系：片内逻辑分析仪（ILA）、信号探测、板级调试手段，快速定位上板后的功能与时序问题。

**服务场景**：上板验证、接口调试、时序/功能排障。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 手段 | ILA/VIO 片内调试、外部逻辑分析仪 |
| 约束 | 调试逻辑占用资源，需可裁剪 |
| 约束 | 生产版本需移除/禁用调试逻辑 |

## 3. 架构设计

### 3.1 调试手段
| 手段 | 说明 |
|------|------|
| ILA | 片内逻辑分析仪，触发采集 |
| VIO | 虚拟 IO 读写 |
| JTAG | 边界扫描、远程调试 |
| 外部分析仪 | 引脚级信号抓取 |

### 3.2 调试流程
复现问题 → 插入 ILA 探点 → 设触发条件 → 抓波形 → 分析 → 修复。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `ila_probe #(PROBE_WIDTH)` | ILA 探点封装 |
| `clk` | 采样时钟 |
| `probe` | 被观测信号 |
| `trigger` | 触发条件 |

## 5. 关键流程与时序
触发条件满足 → ILA 采集 → 上传波形 → 分析时序/功能。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 调试 | ILA 片内 | 外部分析仪 | 不额外硬件 |
| 探点 | 关键信号 | 全量 | 控制资源 |
| 生产 | 移除调试逻辑 | 保留 | 安全/资源 |

## 7. 性能指标（KPI）
- 问题定位时间。
- 调试逻辑资源开销可控。

## 8. 可靠性设计
- 调试触发可靠，波形可复现。

## 9. 安全设计
- 生产版本禁用调试口（防逆向）。

## 10. 测试与验证策略
- 上板回归 + 调试流程验证。

## 11. 集成与部署
- 调试版本与生产版本分离管理。

## 12. 参考资料
- 厂商 ILA/VIO 工具文档。
- 板级调试方法学。

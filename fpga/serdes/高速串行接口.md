# 高速串行接口

> 模块目录：`workspace/fpga/serdes/` · 接口文件：`rtl/serdes_if.sv`

## 1. 模块定位与目标
建立 FPGA 高速串行接口（SerDes）方案：PCIe、万兆以太网、高速 SerDes，实现与 RK3588、网络、存储的高带宽互联。

**服务场景**：FPGA 与 RK3588 的 PCIe 互联、网关万兆上行、高速采集回传。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| SerDes | 高速收发器（Gbps 级） |
| 协议 | PCIe Gen3/4、10G/25G 以太网 |
| 约束 | 信号完整性、时钟恢复、编码 |

## 3. 架构设计

### 3.1 接口层次
```
协议层(PCIe/MAC) → PCS(编码/对齐) → PMA(SerDes) → 物理链路
```

### 3.2 关键要素
| 要素 | 说明 |
|------|------|
| 8b/10b、64b/66b 编码 | 直流平衡 |
| 时钟恢复 | CDR |
| 均衡 | 预加重/均衡补偿 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `serdes_if #(LANES, DATA_WIDTH)` | SerDes 收发器 |
| `ref_clk_p/n` | 参考时钟 |
| `rx_p/n、tx_p/n` | 高速差分 |
| `link_up/lane_aligned/bit_error_count` | 链路状态 |
| `rx_data/tx_data` | AXI-Stream 数据 |
| `pcie_ep` | PCIe Endpoint |

## 5. 关键流程与时序
链路训练 → 锁定 → 数据收发。PCIe 经枚举与配置（见 platform/pcie-usb-storage）。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 互联 | PCIe | 其他 | 低延迟高带宽 |
| 上行 | 万兆以太网 | 千兆 | 网关吞吐 |
| IP | 厂商 IP 核 | 自研 | 可靠成熟 |

## 7. 性能指标（KPI）
- 链路带宽、误码率（BER）。
- 链路稳定性。

## 8. 可靠性设计
- 链路错误检测/重传（协议层）。
- 信号完整性设计与测试。

## 9. 安全设计
- 链路加密/认证（可选）。

## 10. 测试与验证策略
- 信号完整性测试（眼图/误码）。
- 链路压力测试。

## 11. 集成与部署
- IP 核版本与约束管理。

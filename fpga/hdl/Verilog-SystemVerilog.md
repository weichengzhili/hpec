# Verilog / SystemVerilog

> 模块目录：`workspace/fpga/hdl/` · 接口文件：`rtl/module_template.sv`

## 0. 问题定位

- **解决什么问题**：RTL 如何可综合、无锁存器。
- **边界标准**：
  1. 可综合，无推断锁存器，风格一致。
- **系统位置**：环 3、环 5、环 6。

## 1. 模块定位与目标
建立可综合的 RTL 设计规范：SystemVerilog 用于设计（可综合子集）与验证，规范时序逻辑/组合逻辑风格、状态机编码、参数化，确保代码可靠、可维护、可综合。

**服务场景**：所有 FPGA 设计模块的 RTL 编写。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 语言 | Verilog-2001 / SystemVerilog（可综合子集） |
| 可综合 | 遵循可综合风格，避免不可综合构造 |
| 约束 | 组合/时序逻辑清晰分离 |

## 3. 架构设计

### 3.1 设计风格
| 风格 | 说明 |
|------|------|
| 时序逻辑 | always_ff，非阻塞赋值 <= |
| 组合逻辑 | always_comb，阻塞赋值 = |
| 状态机 | 三段式/二段式，enum 编码 |
| 参数化 | parameter/generate |

### 3.2 编码规范要点
- 敏感列表完整（或用 always_comb/always_ff 自动）。
- 复位策略统一（同步/异步明确）。
- 禁止 always 中混合阻塞/非阻塞赋值。
- 命名与层次规范。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `module module_template #(WIDTH, SYNC_RESET)` | 参数化模块 |
| `clk/rst_n` | 时钟/低有效复位 |
| `din/din_valid/dout/dout_valid` | 数据握手 |
| `state_t` | enum 状态机编码 |

## 5. 关键流程与时序
RTL 描述 → 综合成门级网表 → 映射到 LUT/FF/BRAM。时序逻辑由 FF 实现，组合逻辑由 LUT 实现。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 赋值 | 时序 <= 组合 = | 混用 | 避免竞争 |
| 复位 | 统一策略 | 各自 | 可预测 |
| 编码 | enum 状态机 | 裸数值 | 可读、防错 |

## 7. 性能指标（KPI）
- 代码 lint 清零（可综合性检查）。
- 功能仿真覆盖率达标。

## 8. 可靠性设计
- 避免锁存器（不完整 if/case）。
- 状态机覆盖默认分支。

## 9. 安全设计
- 可综合子集限制，防隐藏行为。

## 10. 测试与验证策略
- lint 检查（可综合性）。
- 功能仿真 + 断言。

## 11. 集成与部署
- 编码规范文档 + lint 工具配置入仓。

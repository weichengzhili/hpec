# FPGA 开发总览

> 模块目录：`workspace/fpga/overview/` · 接口文件：`rtl/fpga_top.sv`

## 1. 模块定位与目标
建立 FPGA 开发的整体工程体系：器件选型、工具链、开发流程、工程化管理，为后续设计/验证/调试模块提供全局框架与规范。

**服务场景**：工业机器人实时接口、网关协议桥接、高速采集、算法加速。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 器件 | 按资源/接口/速度等级选型（LUT/FF/BRAM/DSP/SerDes） |
| 工具链 | Vivado / Quartus / 国产 EDA |
| 流程 | RTL → 综合 → 布局布线 → 时序收敛 → 生成位流 |
| 约束 | 版本化、可复现构建 |

## 3. 架构设计

### 3.1 开发流程（V 模型）
```
需求 → 架构设计 → RTL 设计 → 功能仿真 → 综合 → 布局布线 → 时序收敛 → 位流生成 → 上板验证
                     ↑             ↓
                  验证平台     静态时序分析
```

### 3.2 工程化要素
| 要素 | 说明 |
|------|------|
| 代码规范 | RTL 可综合风格（见 hdl） |
| 约束文件 | XDC/SDC 时序约束（见 timing） |
| 版本控制 | IP、约束、脚本入仓 |
| 可复现 | 锁定工具版本与构建脚本 |

## 4. 接口设计

顶层 `fpga_top` 接口：
| 端口 | 说明 |
|------|------|
| `clk/rst_n` | 时钟与复位 |
| `serdes_rx/tx_p/n` | 高速串行（SerDes） |
| `axi_s` | AXI 接口（连 RK3588） |
| `enc_a/b/z` | 编码器接口 |
| `ethercat_irq` | 实时总线中断 |
| `gpio[15:0]` | 通用 IO |

## 5. 关键流程与时序
综合前仿真 → 综合 → 布局布线后仿真 → STA → 位流 → 上板调试。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 器件 | 按资源与 SerDes 需求 | 任意 | 成本/性能 |
| 流程 | 脚本化构建 | 手动 | 可复现 |
| 验证 | 仿真 + 断言 | 仅上板 | 提前发现问题 |

## 7. 性能指标（KPI）
- 时序收敛（无违例）。
- 资源利用率（LUT/BRAM/DSP）。
- 功能覆盖率、代码覆盖率。

## 8. 可靠性设计
- 时序余量、跨时钟域处理（见 cdc）。
- 复位策略、亚稳态防护。

## 9. 安全设计
- 位流加密与认证（防逆向/篡改）。
- 调试口安全控制。

## 10. 测试与验证策略
- 功能仿真 + 时序仿真 + 上板验证。
- 回归测试脚本化。

## 11. 集成与部署
- 位流版本化，与固件联动发布。

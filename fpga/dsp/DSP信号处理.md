# DSP 信号处理

> 模块目录：`workspace/fpga/dsp/` · 接口文件：`rtl/fir_filter.sv`

## 1. 模块定位与目标
用 FPGA DSP 资源（DSP48 等）实现定点信号处理：FIR/IIR 滤波、FFT、CORDIC、定点运算，支撑实时信号处理与控制。

**服务场景**：编码器/伺服滤波、振动/电流采样处理、调制解调、传感器信号调理。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 资源 | DSP48/乘法器/累加器 |
| 定点 | 定点运算精度与溢出控制 |
| 约束 | 实时吞吐满足采样率 |

## 3. 架构设计

### 3.1 常用算法
| 算法 | 用途 |
|------|------|
| FIR 滤波器 | 低通/带通/陷波 |
| FFT | 频谱分析 |
| CORDIC | 三角函数/坐标旋转 |
| 乘法累加 (MAC) | 滤波/相关 |

### 3.2 实现要点
- 定点格式（Q 格式）与位宽规划。
- 流水线提升吞吐。
- 溢出/饱和处理。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `fir_filter #(DATA_WIDTH, COEF_WIDTH, NUM_TAPS, OUT_WIDTH)` | FIR 滤波器 |
| `fft_core #(FFT_SIZE, DATA_WIDTH)` | FFT |
| `cordic #(WIDTH)` | CORDIC |
| `data_in/data_out` | AXI-Stream 数据流 |
| `coef[]/coef_valid` | 系数配置 |

## 5. 关键流程与时序
采样 → 定点化 → 滤波/FFT → 定点结果 → 输出。流水线满足连续采样吞吐。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 定点 vs 浮点 | 定点 | 浮点 | 资源/功耗效率 |
| 结构 | 流水线/并行 | 串行 | 吞吐优先 |
| 精度 | 位宽与饱和控制 | 无 | 防溢出 |

## 7. 性能指标（KPI）
- 处理吞吐（采样率满足）。
- 精度（SNR/误差）。
- DSP 资源利用率。

## 8. 可靠性设计

## 9. 安全设计

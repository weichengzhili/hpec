# 验证与 UVM

> 模块目录：`workspace/fpga/verification/` · 接口文件：`tb/dut_if.sv`

## 1. 模块定位与目标
建立 FPGA 验证体系：功能仿真、约束随机验证、断言、UVM 验证方法学，在流片/上板前最大化发现缺陷，保证设计正确性。

**服务场景**：所有 FPGA 模块的验证，尤其是复杂 SoC/接口模块。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 方法学 | UVM / 轻量级 SV 验证 |
| 目标 | 功能覆盖率 + 代码覆盖率达标 |
| 约束 | 验证环境可复用、可回归 |

## 3. 架构设计

### 3.1 验证层次
| 层次 | 说明 |
|------|------|
| 单元验证 | 模块级功能 |
| 集成验证 | 模块互联 |
| 系统验证 | 软硬件协同 |

### 3.2 UVM 组件
| 组件 | 说明 |
|------|------|
| Driver | 驱动激励 |
| Monitor | 采集监控 |
| Scoreboard | 结果比对 |
| Sequence | 激励序列 |
| Agent | 组件封装 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `dut_if` | 验证接口（连接 DUT） |
| `clocking cb` | 驱动/采样时序 |
| `assert property` | 断言监控 |
| `modport tb/dut` | 方向定义 |

## 5. 关键流程与时序
构建激励 → 驱动 DUT → 采集响应 → 比对参考模型 → 覆盖率统计 → 回归。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 方法学 | UVM | 裸 TB | 复用、标准化 |
| 激励 | 约束随机 | 定向 | 覆盖边界 |
| 比对 | Scoreboard + 参考模型 | 人工 | 自动检查 |

## 7. 性能指标（KPI）
- 功能覆盖率、代码覆盖率。
- 缺陷在仿真阶段发现率。

## 8. 可靠性设计
- 断言监控协议违例。
- 回归测试防退化。

## 9. 安全设计
- 关键路径形式化验证（可选）。

## 10. 测试与验证策略
- UVM 环境 + 断言 + 覆盖率 + 回归。

## 11. 集成与部署
- 验证环境版本化，纳入 CI 回归。

## 12. 参考资料
- UVM 标准（IEEE 1800.2）。
- 验证方法学最佳实践。

## 关联模块
- `fpga/hdl`：被验证对象。
- `fpga/axi`：协议检查。
- `fpga/debug`：验证与调试协同。

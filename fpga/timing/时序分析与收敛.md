# 时序分析与收敛

> 模块目录：`workspace/fpga/timing/` · 接口文件：`constraints/timing.sdc`

## 1. 模块定位与目标
建立静态时序分析（STA）与时序收敛体系：时钟约束、建立/保持时间、时钟歪斜、关键路径优化，确保设计在目标频率稳定工作。

**服务场景**：高速设计、多时钟域、SerDes 接口时序。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 目标 | 满足建立/保持时间，无时序违例 |
| 约束 | 时钟、输入输出延迟、时序例外 |
| 约束 | 需完整 SDC 约束 |

## 3. 架构设计

### 3.1 时序要素
| 要素 | 说明 |
|------|------|
| 建立时间 (setup) | 数据在时钟沿前稳定 |
| 保持时间 (hold) | 数据在时钟沿后保持 |
| 时钟歪斜 (skew) | 时钟到达不同 FF 的差异 |
| 关键路径 | 延迟最大的路径 |

### 3.2 时序收敛手段
- 时钟约束（create_clock）。
- 输入/输出延迟约束。
- 流水线插入、逻辑重定时。
- 时序例外（多周期路径、伪路径）。

## 4. 接口设计

| 约束 | 说明 |
|------|------|
| `create_clock` | 主时钟约束 |
| `create_generated_clock` | 生成时钟（PLL 输出） |
| `set_input_delay/set_output_delay` | IO 延迟 |
| `set_false_path` | 跨时钟域伪路径 |
| `set_multicycle_path` | 多周期例外 |

## 5. 关键流程与时序
约束 → 综合 → 布局布线 → STA → 违例分析 → 优化 → 迭代收敛。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 优化 | 流水线 | 并行 | 提升频率 |
| 约束 | 完整 SDC | 部分 | STA 准确性 |
| 例外 | 谨慎使用伪路径 | 滥用 | 避免掩盖真问题 |

## 7. 性能指标（KPI）
- 最高工作频率（Fmax）。
- 时序违例 = 0。
- 时序余量（slack）。

## 8. 可靠性设计
- 留时序余量应对工艺/温度变化。
- 跨时钟域专门处理（见 cdc）。

## 9. 安全设计
- 时序收敛保证功能确定性。

## 10. 测试与验证策略
- STA 全覆盖 + 上板实测。
- 高低温/电压时序测试。

# FIFO 与片上存储

> 模块目录：`workspace/fpga/fifo/` · 接口文件：`rtl/fifo.sv`

## 0. 问题定位

- **解决什么问题**：片上 FIFO 如何保证跨时钟域数据不丢、不乱序。
- **边界标准**：
  1. 满/空标志正确，无数据丢失或重复（硬约束）。
  2. 跨时钟域 FIFO 用格雷码指针，无亚稳态（硬约束）。
  3. 深度满足突发流量，有背压防溢出（硬约束）。
- **系统位置**：环 5；`fpga/cdc` → 本模块 → `fpga/axi`。

## 1. 模块定位与目标
建立片上存储（BRAM/分布式 RAM）与 FIFO 的使用规范：同步/异步 FIFO、读写控制、满/空标志、深度计算，支撑数据缓存与速率匹配。

**服务场景**：数据通路缓存、跨时钟域缓冲、速率匹配、接口缓冲。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 存储 | BRAM（大容量）/ 分布式 RAM（小容量） |
| FIFO | 同步/异步、满/空管理 |
| 约束 | 深度计算满足吞吐与突发 |

## 3. 架构设计

### 3.1 FIFO 类型
| 类型 | 说明 |
|------|------|
| 同步 FIFO | 同时钟读写 |
| 异步 FIFO | 跨时钟域（见 cdc） |
| FWFT | 首字直通模式 |

### 3.2 关键信号
| 信号 | 说明 |
|------|------|
| 写使能/数据 | 写入侧 |
| 读使能/数据 | 读出侧 |
| full/empty | 满/空标志 |
| almost_full/empty | 预警（水线） |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `sync_fifo #(WIDTH, DEPTH, FWFT)` | 同步 FIFO |
| `bram #(WIDTH, DEPTH)` | BRAM 封装 |
| 满/空/水线标志 | 流控 |

## 5. 关键流程与时序
写入满则背压（流控），读出空则等待。水线标志提前触发流控，避免溢出/欠载。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 存储 | BRAM vs 分布式 | 单一 | 容量/延迟权衡 |
| 异步 | 异步 FIFO 跨域 | 同步 | 数据安全 |
| 流控 | 水线标志 | 仅满/空 | 提前背压 |

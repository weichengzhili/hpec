# 跨时钟域 CDC

> 模块目录：`workspace/fpga/cdc/` · 接口文件：`rtl/cdc_sync.sv`

## 1. 模块定位与目标
建立跨时钟域（CDC）信号传递的可靠方案：亚稳态处理、多级同步、握手、异步 FIFO，防止数据损坏与不可预测行为。是 FPGA 多时钟设计的核心可靠性问题。

**服务场景**：多时钟设计、异步接口（PCIe/EtherCAT/外设）、SoC 时钟切换。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 亚稳态 | 用同步器消除亚稳态传播 |
| 数据一致性 | 多 bit 跨域需握手/FIFO |
| 约束 | CDC 结构需工具可检测 |

## 3. 架构设计

### 3.1 CDC 处理方案
| 场景 | 方案 |
|------|------|
| 单 bit 控制信号 | 双级触发器同步器 |
| 多 bit 数据 | 握手、异步 FIFO、格雷码 |
| 总线 | 异步 FIFO |
| 复位 | 复位同步器 |

### 3.2 亚稳态
亚稳态是触发器在建立/保持窗口内采样导致的中间状态。多级同步器降低亚稳态传播概率（MTBF）。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `cdc_bit_sync` | 单 bit 双级同步器 |
| `cdc_async_fifo` | 异步 FIFO（多 bit 数据跨域） |
| `cdc_reset_sync` | 复位同步器 |

## 5. 关键流程与时序
源时钟域信号 → 同步器（两级 FF）→ 目标时钟域采样。多 bit 数据经异步 FIFO（读/写指针格雷码）保证一致。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 单 bit | 双级同步 | 单级 | 简单可靠 |
| 多 bit | 异步 FIFO | 多 bit 直传 | 数据一致性 |
| 指针 | 格雷码 | 二进制 | 单 bit 变化跨域安全 |

## 7. 性能指标（KPI）
- CDC 结构覆盖率（工具检测）。
- 亚稳态 MTBF 达标。

## 8. 可靠性设计

- CDC 工具检查（CDC 分析器）。

## 9. 安全设计

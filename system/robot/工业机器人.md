# 工业机器人

> 模块目录：`workspace/system/robot/` · 接口文件：`include/robot_system.hpp`

## 1. 方案定位与目标
面向工业机器人的运动控制与智能化整机方案，以 RK3588 为控制/视觉算力核心，FPGA 承担实时接口与运动控制，结合 PREEMPT_RT 实时内核与视觉伺服，实现多轴高精度运动控制与安全。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 实时 | 运动控制周期（如 1ms/250µs）有界延迟 |
| 通信 | EtherCAT/实时总线，编码器接口 |
| 安全 | 功能安全（安全 IO/安全 PLC/急停） |
| 视觉 | 视觉伺服、目标定位 |
| 约束 | 多轴插补、力控、轨迹规划 |

## 3. 架构设计

### 3.1 软硬件分工
```
RK3588（控制/视觉/规划）
  ├─ 轨迹规划/运动学（C++）
  ├─ 视觉伺服（NPU + 相机）
  └─ Linux + PREEMPT_RT
FPGA（实时接口）
  ├─ EtherCAT 主站/编码器接口
  ├─ 多轴插补/电流环（DSP）
  └─ 安全 IO 逻辑
```

### 3.2 控制环路
| 环路 | 周期 | 执行位置 |
|------|------|----------|
| 电流环 | 最快（µs） | FPGA/伺服驱动器 |
| 速度环 | 快 | FPGA/驱动器 |
| 位置环 | 中（ms） | RK3588/FPGA |
| 轨迹规划 | 慢 | RK3588 |

### 3.3 功能安全
- 安全急停、安全限位（独立安全回路）。
- 安全 PLC 监控、安全速度/位置监控。
- 视觉伺服闭环（目标定位 → 轨迹修正）。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `motion` | 轨迹规划/运动学 |
| `bus` | EtherCAT 实时总线 |
| `servo` | 编码器/伺服 |
| `vision` | 视觉伺服 |
| `safety` | 功能安全 |

## 5. 关键流程与时序
轨迹规划 → 运动学解算 → 插补 → 位置/速度指令 → 伺服（EtherCAT）→ 编码器反馈 → 闭环。视觉伺服周期性修正目标。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 实时 | PREEMPT_RT + 核心隔离 | 标准 | 有界延迟 |
| 接口 | FPGA EtherCAT/编码器 | 软件 | 确定性时序 |
| 控制环 | 分层（快环硬件/慢环软件） | 全软件 | 各取所长 |
| 安全 | 独立安全回路 | 软件 | 功能安全 |

## 7. 性能指标（KPI）
- 运动控制周期与抖动（cyclictest 达标）。
- 轨迹精度、重复定位精度。
- 视觉伺服延迟、安全响应时间。

## 8. 可靠性设计
- 安全回路独立、急停硬接线。
- 编码器失效检测、力/碰撞保护。

## 9. 安全设计
- 功能安全（安全 IO/安全 PLC）。
- 实时总线安全、访问控制。

## 10. 测试与验证策略

- 功能安全验证、碰撞/急停测试。

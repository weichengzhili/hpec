# 工业网关

> 模块目录：`workspace/system/gateway/` · 接口文件：`include/gateway_system.hpp`

## 1. 方案定位与目标
面向工业现场的协议网关与边缘计算节点，以 RK3588 为核心（可选 FPGA 协处理），实现多协议采集（Modbus/OPC-UA/PROFINET/EtherCAT）、协议转换、边缘计算、数据上云，满足工业环境可靠性与实时性。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 协议 | Modbus RTU/TCP、OPC-UA、PROFINET、EtherCAT、MQTT |
| 实时 | TSN 时间敏感网络、确定性转发 |
| 可靠 | 7×24 运行、断点续传、看门狗 |
| 安全 | 身份认证、加密、访问控制 |
| 约束 | 工业温度/防护等级 |

## 3. 架构设计

### 3.1 软硬件分层
```
应用层（协议栈/边缘计算/数据服务）
  ├─ 协议层（Modbus/OPC-UA/MQTT 等）
  ├─ 系统层（Linux，可选 PREEMPT_RT）
  ├─ 驱动/BSP（RK3588 + FPGA 接口）
硬件层（RK3588 + FPGA/串口/网口/CAN）
```

### 3.2 FPGA 协处理分工
| 任务 | 分工 |
|------|------|
| 实时协议（EtherCAT） | FPGA（确定性时序） |
| 高速采集/接口 | FPGA（SerDes/编码器） |
| 协议转换/上云 | RK3588（软件栈） |
| 边缘计算 | RK3588（CPU/NPU） |

### 3.3 数据流
现场设备 → 采集 → 协议解析 → 边缘计算 → 上云。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `field_io` | 现场采集（串口/网口/CAN） |
| `protocol_stack` | 协议处理 |
| `edge_compute` | 边缘计算（过滤/聚合） |
| `cloud` | 上云（MQTT/OPC-UA） |
| `buffer` | 断点续传缓存 |

## 5. 关键流程与时序
采集 → 解析 → 边缘处理 → 本地存储 → 上云。网络中断时本地缓存 + 断点续传。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 实时协议 | FPGA 协处理 | 软件 | 确定性 |
| 协议栈 | 软件实现 | 硬件 | 灵活 |
| 上云 | MQTT | 私有 | 轻量、可靠 |
| 缓存 | 本地存储断点续传 | 无 | 可靠 |

## 7. 性能指标（KPI）
- 协议采集周期、实时性（TSN 时延）。
- 数据转发吞吐、上云延迟。
- 断点续传完整率、可用性（如 99.99%）。

## 8. 可靠性设计
- 看门狗、断点续传、本地缓存。
- 双网口冗余、故障切换。

## 9. 安全设计
- 设备认证、TLS 加密、访问控制。
- 最小权限、供应链审计（见 kernel/security）。

## 10. 测试与验证策略
- 多协议互通测试、TSN 时延测试。
- 断网/重连、长时间稳定性测试。

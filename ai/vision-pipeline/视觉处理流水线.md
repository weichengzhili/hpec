# 视觉处理流水线

> 模块目录：`workspace/ai/vision-pipeline/` · 接口文件：`include/vision_pipeline.hpp`

## 1. 模块定位与目标
建立端到端视觉 AI 处理流水线：图像采集 → 预处理 → 推理 → 后处理 → 业务消费，通过零拷贝与多路复用实现高吞吐低延迟。

**服务场景**：机器人视觉、舱内/车载感知、工业检测、监控分析。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 采集 | MIPI-CSI 相机（见 platform/mipi-csi） |
| 处理 | 预处理/推理/后处理 |
| 约束 | 端到端延迟与吞吐达标 |

## 3. 架构设计
```
采集(V4L2) → 预处理(缩放/归一化) → 推理(NPU) → 后处理(NMS/解码) → 业务
```

### 3.1 阶段职责
| 阶段 | 说明 |
|------|------|
| 采集 | 相机出帧（dmabuf） |
| 预处理 | 缩放/颜色转换/归一化 |
| 推理 | NPU 前向（见 npu-runtime） |
| 后处理 | 检测框解码、NMS、跟踪 |

### 3.2 优化
- dmabuf 零拷贝贯穿全链。
- 多路复用、流水线并行。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `detection_box/vision_result` | 检测结果 |
| `pipeline_stages` | 预处理/后处理回调 |
| `vision_pipeline::init/start/stop()` | 生命周期 |
| `process_frame()/process_frame_async()/get_result()` | 帧处理 |

## 5. 关键流程与时序
出帧 → 预处理 → 推理 → 后处理 → 结果。多路视频可并行流水线（不同阶段重叠执行）。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 缓冲 | dmabuf 零拷贝 | 拷贝 | 降低带宽/延迟 |
| 并行 | 流水线/多路 | 串行 | 提升吞吐 |
| 后处理 | 硬件/CPU 分工 | 纯 CPU | 性能 |

## 7. 性能指标（KPI）
- 端到端延迟、多路 FPS。
- 内存带宽占用。

## 8. 可靠性设计

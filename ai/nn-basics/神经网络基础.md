# 神经网络基础

> 模块目录：`workspace/ai/nn-basics/` · 接口文件：`include/tensor.hpp`

## 1. 模块定位与目标
建立神经网络推理的基础知识：网络结构（卷积/全连接/注意力）、算子、张量、推理计算原理，为量化、部署、优化提供理论支撑。

**服务场景**：所有 AI 模块的基础，模型理解与算子分析。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 结构 | CNN、Transformer、检测/分割/分类网络 |
| 算子 | 卷积、激活、池化、归一化、全连接 |
| 约束 | 边缘设备算子支持范围（见 npu-runtime） |

## 3. 架构设计

### 3.1 典型网络结构
| 网络 | 用途 |
|------|------|
| CNN 分类 | 图像分类（ResNet/EfficientNet） |
| 目标检测 | YOLO 系列 |
| 分割 | UNet/DeepLab |
| Transformer | 视觉 ViT 等 |

### 3.2 核心算子
| 算子 | 说明 |
|------|------|
| 卷积 (Conv) | 特征提取 |
| 激活 (ReLU/SiLU) | 非线性 |
| 池化 (Pool) | 降采样 |
| 归一化 (BN/LN) | 稳定训练 |
| 全连接 | 分类头 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `dtype` | 数据类型（uint8/int8/fp16/fp32...） |
| `layout` | 张量布局（NCHW/NHWC） |
| `tensor` | 张量描述（dims/type/layout/data） |
| `tensor_size()/reshape()/convert_layout()` | 张量工具 |
| `op_type` | 算子类型枚举 |

## 5. 关键流程与时序
推理前向传播：输入张量 → 逐层算子计算 → 输出特征/结果。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 精度 vs 速度 | 轻量网络 | 大网络 | 边缘适配 |
| 布局 | NHWC（NPU 偏好） | NCHW | 硬件效率 |

## 7. 性能指标（KPI）
- 模型 FLOPs、参数量。
- 单层算力需求。

## 8. 可靠性设计
- 算子精度验证（见 quantization）。

## 9. 安全设计
- 模型结构可审计。

## 10. 测试与验证策略
- 逐层算子输出比对。

## 11. 集成与部署
- 模型格式标准化（ONNX 中间表示）。

## 12. 参考资料
- 深度学习基础（CNN/Transformer）。
- ONNX 算子规范。

# 性能优化与评测

> 模块目录：`workspace/ai/performance/` · 接口文件：`include/benchmark.hpp`

## 0. 问题定位

- **解决什么问题**：推理延迟/吞吐/精度/功耗如何被正确度量，为优化提供依据。
- **边界标准**：
  1. 延迟/吞吐/功耗有基准和测量方法（硬约束）。
  2. 测量结果可复现（给定输入和状态）（硬约束）。
  3. 精度损失有量化（相对浮点基准）（硬约束）。
- **系统位置**：环 7；`npu-runtime`、`vision-pipeline` → 本模块。

## 1. 模块定位与目标
建立边缘 AI 性能优化与评测体系：延迟/吞吐/精度/功耗指标定义、瓶颈定位、优化手段（算子融合、量化、批处理、内存复用），形成可量化的优化闭环。

**服务场景**：AI 部署性能达标与持续优化。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 指标 | 延迟/吞吐/精度/功耗/内存 |
| 约束 | 优化不损害精度与稳定性 |

## 3. 架构设计

### 3.1 评测指标
| 指标 | 说明 |
|------|------|
| 延迟 | 单帧端到端/纯推理 |
| 吞吐 | FPS/多路 |
| 精度 | mAP/准确率 |
| 功耗 | 单帧/持续功耗 |
| 内存 | 峰值/常驻 |

### 3.2 优化手段
| 手段 | 说明 |
|------|------|
| 量化 | INT8（见 quantization） |
| 算子融合 | 减少中间张量 |
| 批处理 | 提升吞吐 |
| 内存复用 | 降低峰值 |
| 零拷贝 | 减少搬运 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `benchmark_result` | 评测结果（延迟/吞吐/精度/功耗/内存） |
| `benchmark_config` | 评测配置 |
| `benchmark::run()` | 跑基准 |
| `evaluate_accuracy()` | 精度评测 |
| `generate_report()` | 报告生成 |

## 5. 关键流程与时序
基准测试 → 瓶颈定位（推理/预处理/后处理）→ 优化 → 回归评测 → 对比。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 延迟 vs 吞吐 | 按场景取舍 | 单一 | 交互 vs 批处理 |
| 精度 vs 速度 | 量化平衡 | 极致 | 达标前提 |

## 7. 性能指标（KPI）
- 各指标达标（延迟/吞吐/精度/功耗）。

## 8. 可靠性设计

# NPU 推理运行时

> 模块目录：`workspace/ai/npu-runtime/` · 接口文件：`include/rknn_runtime.hpp`

## 1. 模块定位与目标
建立 NPU 推理运行时方案：RKNN Runtime 加载 .rknn 模型、张量管理、推理执行、多模型/多线程管理，实现高效稳定的推理服务。

**服务场景**：RK3588 NPU 推理（与 platform/npu 对应）。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 运行时 | RKNN Runtime（C/Python） |
| 约束 | 输入输出张量布局（NHWC）、内存管理 |
| 约束 | 多模型/多核 NPU 调度 |

## 3. 架构设计

### 3.1 运行时组件
| 组件 | 说明 |
|------|------|
| 模型加载 | 解析 .rknn |
| 张量管理 | 输入/输出张量分配 |
| 推理执行 | 调用 NPU 计算 |
| 生命周期 | 初始化/推理/释放 |

### 3.2 多模型管理
- 多模型加载与切换。
- NPU 三核任务调度。

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `rknn_context` | 运行时句柄 |
| `tensor_attr` | 张量属性 |
| `rknn_runtime::load/unload()` | 模型加载 |
| `get_input_attr/get_output_attr()` | 张量属性 |
| `set_input/set_output()` | 零拷贝 DMA |
| `inference()/verify_model()` | 推理/校验 |

## 5. 关键流程与时序
加载模型 → 分配输入输出 → 预处理 → 推理 → 后处理 → 释放。多模型按需切换。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 输入 | 零拷贝 DMA | 拷贝 | 降低搬运开销 |
| 内存 | 复用缓冲 | 每次分配 | 减少分配 |
| 并发 | 多核调度 | 单核 | 提升吞吐 |

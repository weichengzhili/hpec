# 边缘 AI 总览

> 模块目录：`workspace/ai/overview/` · 接口文件：`include/ai_pipeline.hpp`

## 1. 模块定位与目标
建立边缘 AI 的整体架构：算力选型（CPU/GPU/NPU）、推理管线、云边协同，明确边缘推理的收益（低延迟、隐私、带宽节省）与设计原则。

**服务场景**：AI 边缘部署、机器人视觉、舱内感知、网关智能分析。

## 2. 需求与约束
| 类别 | 要求 |
|------|------|
| 算力 | RK3588 NPU 6 TOPS 为主 |
| 指标 | 低延迟、低功耗、隐私 |
| 约束 | 边缘算力/内存/功耗有限 |

## 3. 架构设计

### 3.1 边缘推理管线
```
数据采集 → 预处理 → 推理(NPU) → 后处理 → 结果/动作
```

### 3.2 云边协同
| 模式 | 说明 |
|------|------|
| 纯边缘 | 全在边缘推理 |
| 边缘+云 | 边缘轻推理 + 云重推理/训练 |
| 边云协同更新 | 模型下发、数据回传 |

## 4. 接口设计

| 接口 | 说明 |
|------|------|
| `pipeline::load_model/infer/infer_async` | 统一推理管线 |
| `pipeline_config` | 管线配置（多路/零拷贝/超时） |
| `create_pipeline()/destroy_pipeline()` | 工厂 |

## 5. 关键流程与时序
采集 → 预处理 → 推理 → 后处理 → 输出。管线需保证端到端延迟达标。

## 6. 设计决策与权衡
| 决策点 | 选择 | 备选 | 理由 |
|--------|------|------|------|
| 算力 | NPU | CPU/GPU | 能效比高 |
| 部署 | 边缘为主 | 云端 | 低延迟/隐私 |
| 模型 | 轻量化/量化 | 大模型 | 适配边缘 |

## 7. 性能指标（KPI）
- 端到端延迟、吞吐（FPS）。
- 功耗（TOPS/W）、精度。

## 8. 可靠性设计
- 推理超时看护、异常恢复。
- 模型加载/切换原子性。

## 9. 安全设计
- 模型加密、数据隐私（见 security）。

## 10. 测试与验证策略
- 精度/性能回归、稳定性。

## 11. 集成与部署
- 模型与推理引擎版本化管理（见 mlops）。
